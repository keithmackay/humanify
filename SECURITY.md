# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

Please do not open a public issue for a security problem. Report it privately by either:

- using GitHub's [private vulnerability reporting](https://github.com/keithmackay/humanify/security/advisories/new) for this repository, or
- emailing technofacto@gmail.com with a description, steps to reproduce, and the affected version.

humanify is a prompt-only skill with no executable code, so relevant reports are most likely about instructions that could cause unintended file access, edits, or data exposure when the skill runs.

## Response Timeline

- Acknowledgment within 5 business days.
- An initial assessment within 14 days.
- A fix or mitigation, with credit to the reporter if wanted, once the issue is confirmed.
