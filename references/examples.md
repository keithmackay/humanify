# Worked Before/After Examples

Consult this file when applying a fix (`SKILL.md` Workflow step 5) for one of the categories below — they require judgment about *what to substitute*, and abstract rules under-constrain that more than any other check. One representative pair per category; apply the same reasoning to other instances.

## Copula substitution

- Before: "The new API serves as the foundation for every downstream integration."
- After: "The new API is the foundation for every downstream integration."
- Why: "serves as" adds no meaning "is" doesn't already carry. Run the test from `SKILL.md`: if "is"/"has" reads cleaner, use it.

## Elegant variation

- Before: "The protagonist hesitates at the door. The main character has never liked goodbyes. Our hero finally turns the handle."
- After: "She hesitates at the door. She has never liked goodbyes. She finally turns the handle."
- Why: three synonyms for one person read as a thesaurus reaching for variety, not as description. Repeat the noun or drop to a pronoun once the referent is established.

## Tailing negations

- Before: "The new process cuts approval time in half - no guessing, no wasted motion."
- After: "The new process cuts approval time in half. Approvers know exactly what's needed and when, so nothing sits waiting on a guess."
- Why: the clipped fragments assert a benefit without earning it. Write the actual mechanism as a full clause instead of a rhythmic tag.

## False ranges

- Before: "This pattern shows up everywhere, from startup garages to enterprise boardrooms."
- After: "This pattern shows up in early-stage startups and in established enterprises alike."
- Why: "garages" and "boardrooms" aren't points on a real scale - the range implies a spectrum that doesn't exist. Name the actual categories.

## Participle-ending sentences

- Before: "The team shipped the redesign a week early, reflecting a broader commitment to speed."
- After: "The team shipped the redesign a week early. Speed has been a stated priority since the quarter started."
- Why: the trailing participle clause ("reflecting...") gestures at significance instead of stating it. Split into a second sentence that says the thing directly, or cut it if it doesn't add information.
